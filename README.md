## ❓ Troubleshooting

### Game does not open

- Make sure you extracted the ZIP file completely
- Double-click `index.html`, not any other file
- Use a modern browser (Chrome, Edge, or Firefox)
- Disable browser extensions that block local files

### Game looks broken

- Refresh the page (F5 key)
- Clear your browser cache
- Try a different browser

### Nothing happens when I type

- Click inside the text box first
- Make sure your keyboard is working
- Type the full name as it appears in the show
